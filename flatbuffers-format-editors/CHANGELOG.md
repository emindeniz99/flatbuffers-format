## [0.1.0] - Unreleased

### Added
- Initial release with three editor-side entrypoints, all wrapping the
  `flatbuffers-format` engine:
  - **`flatbuffers-format-editors/codemirror`** — CodeMirror 6
    `StreamLanguage` covering keywords, builtin types, constants,
    numbers (decimal/hex/hex-float/exponent), strings, line/doc/block
    comments. Plus a `formatCommand` + `formatKeymap()` bound to
    Ctrl/Cmd+Shift+F that calls the engine in-process (no CLI).
  - **`flatbuffers-format-editors/monaco`** — Monaco Monarch tokenizer
    + language configuration + `DocumentFormattingEditProvider`.
    `registerFlatBuffers(monaco)` does the whole setup in one call.
  - **`flatbuffers-format-editors/web-component`** — drop-in
    `<flatbuffers-editor>` custom element backed by CodeMirror.
    Sprinkle one onto any HTML page, get highlighting +
    format-on-Ctrl/Cmd+Shift+F with zero JS plumbing.
- Shared token vocabulary (`src/tokens.ts`) keeps the three
  integrations honest against the engine grammar; smoke-tested by
  `test/tokens.test.ts`.
