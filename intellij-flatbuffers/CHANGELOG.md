## [0.1.0] - Unreleased

### Added
- Initial release.
- File-type registration for `.fbs` schemas under the IntelliJ
  Platform's standard file-type service.
- Lexer-driven syntax highlighting: keywords, builtin types,
  numbers, strings, line / doc / block comments, punctuation, bad
  characters. Per-token colour categories exposed under
  Preferences → Editor → Color Scheme → FlatBuffers.
- External formatter integration via
  `AsyncDocumentFormattingService`, shelling out to the
  `flatbuffers-format` CLI.
- Settings page under Preferences → Tools → FlatBuffers with binary
  path, extra CLI arguments, and a format-on-save toggle.
- **Download bundled engine** action on the settings page — fetches
  the matching native `flatbuffers-format` binary from the engine's
  GitHub Release on demand and caches it under the IDE system
  directory. Eliminates the need to `npm install -g flatbuffers-format`
  separately. Supported platforms: linux-x64, linux-arm64,
  macos-x64, macos-arm64, windows-x64.
- Line/block comment toggle support
  (Ctrl/⌘ + / and Ctrl/⌘ + Shift + /).
- Marketplace publish + GitHub Release `.zip` asset via the
  `intellij-flatbuffers` GitHub Actions workflow.

### Compatible with
- All JetBrains IDEs built on IntelliJ Platform 2024.2 or newer.
